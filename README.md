# Explore Uganda — Photo Gallery

A responsive photo gallery for a Uganda tourism website, showcasing some of the country's top destinations.

## Destinations

- Murchison Falls National Park
- Lake Victoria
- Queen Elizabeth National Park
- Bwindi Impenetrable Forest

## Features

- Responsive grid: 3 columns on desktop, 2 on tablets, 1 on phones
- Filter photos by category (Waterfalls & Lakes, Wildlife, Forests)
- Hover captions with place name, description and location
- Lightbox viewer with previous/next buttons and keyboard controls (← → Esc)
- Accessible: alt text, keyboard navigation and reduced-motion support

## Files

| File | Purpose |
| --- | --- |
| `gallery.html` | Page structure and content |
| `style.css` | All styling (theme colours are set at the top under `:root`) |
| `gallery.js` | Filters and lightbox |

## How to view

Open `gallery.html` in a browser, or use the VS Code Live Server extension.
